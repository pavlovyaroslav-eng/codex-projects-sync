# RSSI Checker — rectangular rev3

Исправленная механическая ревизия: строгий прямоугольник **65 × 75 мм** для нормального проектирования корпуса.

## Стороны платы

### Лицевая сторона F

На лицевой стороне установлены только выводные и механические компоненты:

- U2 — ESP32-DevKitC 38 pin;
- U1 — 74HC4051N DIP-16 в панельке;
- C3, C4 — электролиты 220 мкФ 16 В;
- J1 — угловой банановый разъём;
- J2…J7 — угловые разъёмы Signal | +5V | GND;
- J8 — угловой USB-C power, выводное исполнение;
- JP1 и JP2 — две изолированные перемычки.

На F.Cu нет ни одной трассированной дорожки.

### Обратная сторона B

На стороне пайки находятся:

- вся медная трассировка;
- полигон GND;
- R1, R2, R3 — SMD 0805;
- C1, C2, C5 — SMD 0805;
- паяльные площадки всех выводных компонентов.

## Правила

- Размер платы: 65,00 × 75,00 мм.
- Контур: четыре прямые стороны, без вырезов и выступов.
- Основные дорожки: 0,8 мм.
- Короткий выход 3,3 В между контактами DevKitC: 0,3 мм, затем расширение до 0,8 мм.
- Повороты: прямые или 45°.
- Медный слой: только B.Cu.
- Перемычки: ровно 2.
- Антенна ESP32 расположена у правого края; полигон GND под антенной исключён.
- J2…J7 расположены одним рядом у нижнего края.

## Важное по USB-C

J8 выполнен как угловой выводной USB-C power 6P с шагом выводов 2,0 мм и отдельными выводами CC1/CC2. Перед производством нужно сверить посадочное место с конкретным купленным разъёмом. При другом артикуле менять нужно только footprint J8.

## Проверка

Встроенная структурно-геометрическая проверка:

- 20 посадочных мест;
- 74 медных сегмента;
- дорожки только B.Cu;
- SMD только B.Cu;
- THT-компоненты на F;
- 0 пересечений цепей;
- 0 конфликтов дорожка–площадка;
- 0 конфликтов площадка–площадка;
- 0 разрывов сигнальных и питающих цепей;
- 0 диагоналей, отличных от 45°;
- 0 повторяющихся UUID;
- 2 перемычки.

Нативный KiCad DRC не запускался: kicad-cli в среде отсутствует. Перед заказом платы открыть проект, нажать B для перезаливки полигона и выполнить Inspect → Design Rules Checker.
