# НСУ для FPV и антенные системы

## Цель

Разработать технически содержательную концепцию наземной станции управления FPV с принципиальными схемами, каналами управления/видео, переключением частот и антенными решениями.

## Диапазоны

Целевой общий охват после уточнения: примерно от 1000 до 6100 МГц, с отдельными рабочими окнами:

- 1000–2000 МГц;
- 2400–2600 МГц;
- 3100–3600 МГц;
- 3800–4400 МГц;
- 4900–6100 МГц.

## Антенны

- Vivaldi рассматривалась как широкополосный элемент.
- Пользователь уточнил, что нужна не одиночная Vivaldi, а АФАР/фазированная решётка.
- Предпочтение изготовления: печатная технология на текстолите/FR-4 с фоторезистом.
