# Следующие задачи

1. Уточнить безопасный гражданский/лабораторный сценарий и требования по дальности/ЭИИМ.
2. Разделить систему на несколько диапазонных подрешёток вместо нереалистичной единой 1–6,1 ГГц АФАР.
3. Выбрать число элементов, шаг, материал, толщину FR-4 и тип фазовращателей/переключателей.
4. Подготовить модели в CST/HFSS/openEMS и геометрию PCB.
5. Создать блок-схему НСУ: оператор → control TX → антенна → борт; бортовое видео → RX → diversity/switch → монитор/запись.
6. Добавить раздел по измерениям: VNA, КСВ, диаграмма направленности, калибровка каналов.
