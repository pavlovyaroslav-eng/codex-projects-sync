# Политика безопасности

- Все этапы начинаются с read-only аудита.
- Любая операция с диском, загрузчиком или `hometele` выполняется только после
  соответствующей контрольной точки и точного плана отката.
- AI-интерфейсы не публикуются напрямую в Интернет: только localhost, доверенная
  LAN и согласованная VPN-подсеть.
- На Ubuntu SSH и AI-порты 3000/8000/8080/8188 разрешены только контроллеру
  `192.168.1.41/32` и через `tun93` из `10.93.0.0/24`. SSH — key-only,
  `PermitRootLogin no`; Fail2Ban и UFW активны. Passwordless sudo разрешён
  локальному администратору `user` по прямому решению владельца новой выделенной
  машины.
- Open WebUI/ComfyUI/Whisper сейчас не требуют отдельный пароль по решению
  владельца. Доступ ограничен UFW и уникальными клиентскими VPN-сертификатами;
  каждый обладатель VPN-профиля получает доступ к разрешённым AI-портам. Перед
  выдачей профиля другому лицу включить application/reverse-proxy authentication.
- VPN не передаёт default route или DNS и не публикует AI через NAT/DNAT.
  Сертификаты `local-ai` и `owner-laptop` нельзя переиспользовать на других
  устройствах; при утрате профиль нужно отозвать в PKI.
- Windows bootstrap не отключает Defender/Firewall и ограничивает новые правила
  `192.168.1.0/24`.
- Исключение, явно подтверждённое владельцем: RDP без NLA и системный remote logon
  с пустым паролем. RDP/WinRM/SMB разрешены только с контроллера
  `192.168.1.41/32`; SSH при этом принудительно остаётся key-only.
- Приватные SSH/OpenVPN/WireGuard ключи, пароли, recovery passwords, токены,
  cookies и сертификаты с приватным ключом запрещено сохранять в Git.
- В репозитории допустимы публичные ключи и fingerprint.
- Read-only ключ `id_ed25519_vpn_wiki_sync` используется только серверной
  Git-обёрткой и никогда не используется для shell.
- Перед установкой моделей/custom nodes проверяются источник, лицензия, commit,
  install scripts, hashes и открытые критические issues.
- Не выполнять принудительный `kill -9`, форматирование, массовые обновления,
  `docker prune` или изменение firewall/VPN без явного согласованного шага.
- GPU-профили взаимно исключаются через systemd/`ai-mode`; прямой ручной запуск
  конфликтующих units не считается поддерживаемым способом эксплуатации.
