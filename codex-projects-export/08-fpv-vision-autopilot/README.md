# FPV vision autopilot на Raspberry Pi 5

## Цель

Исследовательский прототип лёгкого бортового ПО, подключаемого к полётному контроллеру и использующего собственную камеру и датчики FC без GPS/GLONASS/BeiDou.

## Исходная платформа

- FPV-дроны ориентировочно 5–20 дюймов.
- Raspberry Pi 5.
- Полётный контроллер, камера, аккумулятор, ELRS и видеопередатчик.
- Навигация: визуальная одометрия/оптический поток плюс IMU/барометр и данные полётного контроллера.
