# Правила агента

- Приоритет: безопасность, симуляция и стендовые испытания.
- Не отключать ручной takeover и failsafe.
- Не разрабатывать функции выбора или поражения целей.
- Не считать визуальную одометрию надёжной без тестов на задержку, освещение и потерю текстуры.
- Код разделять на perception, state estimation, planner, command interface, logging и safety supervisor.
