# Windows QR tools

## Цель

Набор переносимых Windows-инструментов без обязательной установки Python:

1. Файл → AES-256 ZIP → облачная выгрузка → QR-ссылка.
2. Excel → минимальный текст → QR-код.

## Принятые решения

- Шифрование ZIP включено всегда.
- Используется 7-Zip AES-256.
- Порядок провайдеров: `tmpfiles` → `litterbox` → `x0`.
- `file.io` исключён.
- Результат создаётся рядом с исходным файлом в папке с суффиксом `_cloud_qr`.
- Окно не должно закрываться при ошибке.
