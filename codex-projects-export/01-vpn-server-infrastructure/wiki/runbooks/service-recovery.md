# Восстановление сервисов

Перед восстановлением зафиксировать текущее состояние, сделать backup, определить зависимые маршруты и подготовить rollback. Не перезапускать критические VPN-компоненты автоматически.

Для Xray на `hometele`: проверить JSON, создать backup, валидировать конфигурацию файлом с расширением `.json`, только затем restart и повторный status. Если проверка не проходит — восстановить выбранный backup и снова валидировать до restart.

Для Matrix сначала проверить Synapse, coturn, nginx, контейнер Synapse Admin и command-agent. Не выдавать Matrix-боту полный shell и не расширять sudo без отдельного аудита.
