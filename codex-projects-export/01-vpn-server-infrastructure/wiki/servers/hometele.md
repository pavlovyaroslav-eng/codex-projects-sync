# hometele

Российская входная точка VPN-каскада. Xray Reality использует TCP 443, nginx-заглушка — TCP 80. OpenVPN `tun79` ведёт к чешскому выходу, а WireGuard `wg-home` обслуживает домашнюю сеть. Postfix принимает доменную почту и пересылает её наружу.

Известное исправление: временный файл проверки Xray должен иметь расширение `.json`; вариант `.tmp` не определялся как JSON. Для HTTPS нельзя занимать TCP 443 поверх Xray.
