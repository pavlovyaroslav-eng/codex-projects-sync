# VPN server infrastructure

## Цель

Поддерживать устойчивую инфраструктуру из трёх серверов без разрушения существующего VPN-каскада, с централизованной WIKI, аудитом конфигураций, Matrix, почтой, мониторингом и безопасным обслуживанием.

## Серверы

- `azazello` — Чехия, внешний шлюз; домен `azazello.raxla.org`, IP `91.242.163.206`.
- `hometele` — RU-мост/видимая точка; домен `hometele.com.ru`, IP `185.71.196.110`.
- `www` — Matrix/Synapse, Nginx, Coturn, Synapse Admin и центральный Git-WIKI.

## Критические ограничения

- Порт TCP 443 на `azazello` и `hometele` занят Xray и является частью рабочего VPN-каскада. Не изменять и не перехватывать без отдельного плана миграции.
- Перед изменением DNS сохранять текущее состояние. Рабочие записи нельзя менять вслепую.
- SSH: нестандартный единый порт, вход по ключу, root login отключён, рабочий пользователь `suazzzi` с sudo.
- Не хранить реальные токены, private keys и пароли в репозитории.
