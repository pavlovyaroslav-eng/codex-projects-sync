# Корпус фары Нива 21214 под Bi-LED

## Цель

Создать пробную STL-модель корпуса фары Нива 21214 под Bi-LED модуль по доступным фотографиям и ориентировочным размерам, затем примерить напечатанную деталь и доработать геометрию в КОМПАС-3D.

## Исходные ориентиры

- Внешний образец: страница OAOK с моделью корпуса фары.
- Дополнительная публикация: Drive2.
- Пользователь готов напечатать пробную модель и уточнить размеры по месту.
- На последнем изображении был отмечен элемент, который требуется убрать, сохранив остальную модель без изменений.
