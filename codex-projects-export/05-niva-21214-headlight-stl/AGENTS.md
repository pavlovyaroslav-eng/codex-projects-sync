# Правила агента

- Не выдавать фотограмметрическую оценку за точные заводские размеры.
- Геометрия должна быть легко редактируемой в КОМПАС-3D.
- Сначала создавать пробный вариант для примерки.
- Удалять только отмеченный элемент, не меняя остальные особенности без команды.
- Сохранять историю размеров и ревизий.
