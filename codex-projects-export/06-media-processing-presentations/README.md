# Обработка фото, видео и презентаций

## Цель

Аккуратно улучшать пользовательские фотографии/видео и собирать презентации строго по предоставленному образцу.

## Основные требования

- Сохранять портретное сходство людей.
- Не менять фон и человека, если задача касается только отдельного предмета.
- Исправлять свет, уровни, блики, мусор и цвет без чрезмерной генеративной перестройки.
- В презентациях строго сохранять шрифты, фон, рамки и место подписи.
- Обычно размещать по две фотографии на слайд.
- Не обрезать людей; при необходимости обрезать стены, стеллажи, ящики и пустой фон.
