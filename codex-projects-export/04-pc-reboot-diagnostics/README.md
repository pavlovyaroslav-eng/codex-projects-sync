# Диагностика самопроизвольных перезагрузок ПК

## Цель

Найти причину внезапных перезагрузок Windows 10 на новом ПК с Ryzen 5 и предотвратить повреждение базы 1С.

## Симптомы

- Перезагрузки без очевидного триггера.
- После некоторых перезагрузок повреждается база 1С.
- Диагностический PowerShell-скрипт сталкивался с ExecutionPolicy, кодировкой консоли и несовместимостью параметров `Out-File`.
