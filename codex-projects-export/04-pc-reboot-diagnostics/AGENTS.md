# Правила агента

- Не объявлять проблему программной или аппаратной без подтверждения логами.
- Сначала строить временную шкалу событий.
- Не удалять дампы и исходные логи.
- Любые стресс-тесты предлагать только с контролем температур и сохранением данных 1С.
- Скрипты должны работать в Windows PowerShell 5.1.
