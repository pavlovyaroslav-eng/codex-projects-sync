# Импорт в Codex

1. Распакуйте архив в локальную папку без кириллицы в пути, например `C:\Codex\yaroslav-projects`.
2. При необходимости создайте Git-репозиторий: `git init`.
3. Добавьте реальные исходники в папки, указанные в `FILES_TO_ADD.md`.
4. Откройте корень либо конкретную подпапку проекта в Codex.
5. Первое сообщение агенту: `Прочитай AGENTS.md и документы проекта. Ничего не изменяй. Составь краткий аудит текущего состояния и список недостающих файлов.`
6. После добавления секретов в локальные файлы убедитесь, что они исключены через `.gitignore`.
