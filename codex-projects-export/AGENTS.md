# Общие правила для Codex

- Основной язык общения и документации: русский.
- Перед изменением существующих файлов сначала прочитать `README.md`, `PROJECT_STATUS.md`, `NEXT_TASKS.md` и локальный `AGENTS.md`.
- Не удалять рабочую конфигурацию ради упрощения.
- Не придумывать отсутствующие значения, размеры, пароли, IP, имена файлов и аппаратные параметры.
- Любые изменения инфраструктуры выполнять только после резервной копии и проверки текущего состояния.
- Не помещать в репозиторий пароли, приватные ключи, API-токены, cookies, секреты MTProto, WireGuard private keys и сертификаты с приватным ключом.
- Новые секреты хранить только в локальных `.env`/`secrets` файлах, исключённых через `.gitignore`.
- Для значимых изменений обновлять `CHANGELOG.md` проекта.
- При работе с медиа сохранять людей, лица, фон и композицию, если явно не указано обратное.
- При работе с CAD/STL сначала делать параметрическую или легко редактируемую тестовую версию, пригодную для последующей доработки в КОМПАС-3D.
