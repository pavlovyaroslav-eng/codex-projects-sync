# Выгрузка проектов для Codex

Эта папка — компактный рабочий контекст по основным проектам Ярослава. Она предназначена для добавления в Codex как единый репозиторий или как набор отдельных проектов.

## Состав

1. `01-vpn-server-infrastructure` — три сервера, VPN-каскад, Matrix, почта, Git-WIKI, аудит конфигураций.
2. `02-home-network-keenetic-rpi` — Keenetic, Raspberry Pi 4, Home Assistant, WireGuard и Telegram.
3. `03-windows-qr-tools` — Windows BAT/PowerShell-инструменты для шифрования, облачной выгрузки и QR.
4. `04-pc-reboot-diagnostics` — диагностика самопроизвольных перезагрузок Windows 10.
5. `05-niva-21214-headlight-stl` — корпус фары Нива 21214 под Bi-LED и подготовка STL.
6. `06-media-processing-presentations` — обработка фото/видео и сборка презентаций по образцу.
7. `07-fpv-ground-station-antennas` — НСУ для FPV, частоты, антенны и АФАР.
8. `08-fpv-vision-autopilot` — автопилот FPV на Raspberry Pi 5 без GNSS.
9. `09-estimates-and-pdf` — сметы, ФЭР и подготовка PDF-таблиц.

## Как добавить в Codex

- Вариант 1: распаковать ZIP и открыть всю папку как один репозиторий.
- Вариант 2: открыть нужную подпапку как отдельный проект.
- В каждом проекте сначала читать `README.md`, затем `PROJECT_STATUS.md`, `NEXT_TASKS.md` и локальный `AGENTS.md`.
- Реальные секреты, пароли, ключи, токены и приватные конфигурации в экспорт намеренно не включены.

## Что нужно добавить вручную

Скопируйте в соответствующие папки исходные скрипты, фотографии, видео, STL/CAD, презентации, диагностические логи и конфиги. Файл `FILES_TO_ADD.md` внутри каждого проекта содержит список рекомендуемых материалов.
