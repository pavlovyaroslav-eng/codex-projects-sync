# Политика обновления

## Пользовательский контур

scripts\Update-UserComponents.ps1 запускается без повышения прав и может:

- создавать очищенную резервную копию конфигурации Codex;
- обновлять Codex CLI только через npm;
- обновлять snapshot настроенных marketplace;
- получать списки установленных и доступных плагинов;
- обновлять разрешённые pipx-пакеты platformio, esptool и cmake;
- восстанавливать локальные зависимости Remotion строго по package-lock.json;
- синхронизировать персональный плагин и переустанавливать его только при изменении содержимого;
- валидировать JSON, TOML и YAML и запускать smoke tests.

## Системный контур

scripts\Update-SystemComponents.ps1 запускается только вручную с повышенными правами. Он:

- читает точные ID из config\packages.json;
- пропускает preview и beta;
- пропускает пакет, если major-версия изменилась или версию нельзя надёжно определить;
- продолжает работу после ошибки отдельного необязательного пакета;
- никогда не удаляет приложения и не использует массовое обновление.

## Расписание

Задача Codex Engineering Toolkit - Weekly Update запускает только пользовательский контур каждое воскресенье в 05:00, не хранит пароль и не запускает второй экземпляр.

## Откат

Для отката использовать последний каталог backups\codex-config-*, восстановить только нужный файл или каталог, затем повторно выполнить Test-EngineeringToolkit.ps1. Файлы авторизации в резервные копии не включаются.
