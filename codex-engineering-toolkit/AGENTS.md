# Правила Codex Engineering Toolkit

- Основной язык документации и отчётов — русский.
- Перед изменением конфигурации Codex запускать scripts\Backup-CodexConfiguration.ps1.
- Не удалять существующие плагины, Skills, MCP, marketplace и пользовательские настройки.
- Не подключаться к серверам, не прошивать устройства и не менять инженерные проекты во время установки или smoke tests.
- Не устанавливать драйверы, WSL, Docker Desktop, CUDA и компоненты с обязательной перезагрузкой без отдельного разрешения.
- Не отключать Defender, UAC, sandbox и Execution Policy.
- Не использовать winget upgrade --all; разрешены только точные package ID из config\packages.json.
- Не сохранять пароли, токены, cookies, приватные ключи и OAuth-данные в toolkit, Git, отчётах и логах.
- Все PowerShell-сценарии должны быть идемпотентными, поддерживать пути с пробелами и кириллицей и сохраняться в UTF-8.
- Перед опасным изменением готовить резервную копию, diff, проверку и план отката.
- Не считать компонент рабочим без успешного smoke test.
