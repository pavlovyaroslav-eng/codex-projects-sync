# RSSI Checker — ESP32-DevKitC rev2

Эта ревизия переделана под фактическую плату с фотографий: **ESP32-DevKitC, 38 контактов (19×2)**, а не отдельный STM32 и не 30-контактный ESP32-модуль.

## Геометрия и монтаж

- Габарит несущей платы: **63,50 × 73,66 мм**, контур Г-образный.
- Посадочное место U2: **48,26 × 27,94 мм**, шаг контактов 2,54 мм, расстояние между рядами 25,40 мм.
- Micro-USB установленной DevKitC обращён к левому вырезу; антенна ESP32 — к правому краю.
- Под антенной исключена заливка GND.
- U1 — **74HC4051N DIP-16 в панельке**.
- Все обычные резисторы и неэлектролитические конденсаторы — **SMD 0805**.
- C3 и C4 — электролиты **220 мкФ, 16 В**, THT.
- J8 — угловой USB-C на правом краю.
- J1 — угловой банановый разъём на левом краю.
- J2…J7 стоят одним рядом у нижнего края; порядок каждого: **Signal | +5V | GND**.

## Трассировка

- Один медный слой: **F.Cu**.
- Основные дорожки: **0,8 мм**.
- Только локальный выход из мелкошаговых площадок USB-C, проход между его экранными лапами и короткий выход 3,3 В между контактами DevKitC: **0,3 мм**; далее питание расширяется до 0,8 мм.
- Все повороты — прямые или 45°.
- Ровно две изолированные проволочные перемычки: **JP1** (общий канал 4051) и **JP2** (сигнал 2.4G).
- Земля выполняется полигоном F.Cu. После открытия платы нажать **B**, затем запустить DRC.

## Назначение ESP32

- GPIO25 → общий вывод Z мультиплексора через JP1.
- GPIO14 → A0/S0.
- GPIO27 → A1/S1.
- GPIO26 → A2/S2.
- GPIO13 → VIDEO через R1 470 Ом на угловой банановый разъём.

Каналы 74HC4051:

| Код A2 A1 A0 | Канал | Разъём |
|---|---|---|
| 000 | Y0 | 500 |
| 001 | Y1 | 300 |
| 010 | Y2 | 2.4G |
| 011 | Y3 | 915 |
| 100 | Y4 | TBS |
| 101 | Y5 | KRL |

Y6 и Y7 не используются и посажены на GND; INH и VEE также на GND. U1 питается от 3,3 В DevKitC.

## Питание

USB-C используется только для питания +5 В; CC1 и CC2 имеют отдельные резисторы 5,1 кОм на GND. Не подавайте питание одновременно через USB-C этой платы и через Micro-USB/выводы питания DevKitC. Espressif разрешает три альтернативных способа питания DevKitC, но предупреждает использовать только один одновременно.

## Проверка

Автоматическая структурно-геометрическая проверка файла платы:

- баланс S-выражений: OK;
- 20 посадочных мест, 80 контактных площадок;
- только F.Cu;
- 0 пересечений между цепями;
- 0 нарушений дорожка–площадка;
- 0 нарушений площадка–площадка;
- 0 разрывов сигнальных/питающих цепей;
- 0 диагоналей, отличных от 45°;
- 2 перемычки.

Нативный KiCad DRC не запускался, потому что kicad-cli в среде отсутствует. Перед производством обязательно открыть проект в KiCad, заполнить полигон клавишей B, выполнить DRC и сверить конкретные артикулы USB-C, бананового и трёхконтактных угловых разъёмов с купленными деталями.
